BACKSTAGE 2.0 — LINK Production Auth
====================================

Backend
- Project: LINK Production
- Provider: Supabase
- BACKSTAGE uses the public/publishable client key only.
- No service_role or administrator secret is bundled in the web app.

Guest behavior
- Home, Discover and Prague remain available without an account.
- The fourth navigation item displays Login.
- The Login page includes Login and Register tabs.

Login
- Existing LINK email + password works in BACKSTAGE.
- Session is persisted by Supabase Auth.
- On successful login, BACKSTAGE reads the signed-in user profile from public.profiles under existing RLS policies.

Register
- Creates a real LINK Auth account, not a separate BACKSTAGE account.
- Sends name and username using the same metadata format as LINK.
- If email verification is required, the page tells the user to verify and return to log in.

Authenticated You page
- Loads LINK name, @username, avatar, verified state/style, role and account_type.
- Navigation label changes from Login to You.
- Sign out removes the BACKSTAGE web session.

Current scope
- BACKSTAGE Follow / Saved Show collections remain device-local in 2.0.
- They are not yet synchronized to Supabase.
